# 🌤️ Weather App

A responsive Weather Application built using **HTML, CSS, and JavaScript** that fetches real-time weather data using a Weather API.

## 🚀 Features

- 🌍 Search weather by city name
- 🌡️ Displays temperature in Celsius
- 💧 Shows humidity level
- 🌬️ Shows wind speed
- ☁️ Dynamic weather icons
- 📱 Fully responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Weather API (OpenWeatherMap or similar)

## ⚙️ How It Works

1. Enter the city name in the search box
2. Click the search button
3. The app fetches real-time weather data from the API
4. Weather details are displayed instantly
