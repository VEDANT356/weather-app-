# 🌤️ Weather App

A modern, responsive weather application that provides live weather updates and forecasts for any city in the world. Built with a focus on clean UI/UX and efficient API integration.

✨ Key Features
🔍 Global Search: Instant weather data for over 200,000 cities.

📍 Geolocation: Get weather updates for your current location with one click.

📊 Detailed Metrics: Real-time stats for Humidity, UV Index, Wind Speed, and Visibility.

📅 5-Day Forecast: Daily breakdowns to help you plan your week.

🎨 Dynamic Themes: Backgrounds and icons that change based on current weather conditions (e.g., sunny, rainy, or snowy).

📱 Fully Responsive: Optimized for Mobile, Tablet, and Desktop screens.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Weather API (OpenWeatherMap or similar)

## ⚙️ How It Works

1. Enter the city name in the search box
2. Click the search button
3. The app fetches real-time weather data from the API
4. Weather details are displayed instantly
