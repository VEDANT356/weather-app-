# 🌦️ Weather Forecast App

A modern, responsive **Weather Forecast Application** that provides real-time weather information and a **5-day forecast** for cities around the world.

Built with **HTML, CSS, JavaScript, and the OpenWeatherMap API**, this project demonstrates API integration, asynchronous JavaScript, browser geolocation, DOM manipulation, and responsive web design.

## ⚙️ How It Works

```text
User Input / Current Location
          ↓
   Weather API Request
          ↓
   Receive JSON Response
          ↓
   Process Weather Data
          ↓
   Update DOM Elements
          ↓
 Current Weather + 5-Day Forecast
```

### Basic Flow

1. User enters a city name or allows location access.
2. JavaScript sends a request to the OpenWeatherMap API.
3. The API returns weather data in JSON format.
4. The application processes the received data.
5. Weather information is displayed dynamically.
6. The interface updates according to the current weather conditions.

## 🔑 API Configuration

This project uses the **OpenWeatherMap API**.

### 1. Get an API Key

Create an account on OpenWeatherMap and generate your API key.

### 2. Add Your API Key

Open the JavaScript file and configure the API key according to your implementation.

```javascript
const API_KEY = "YOUR_API_KEY";
```

> ⚠️ Never upload a private API key to a public GitHub repository. For production projects, use environment variables or a backend service to protect sensitive credentials.
